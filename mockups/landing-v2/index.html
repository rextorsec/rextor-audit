How a review runs

1.0

Scope the diff

The PR diff becomes a change-set of functions and callsites — not a vibe read of the whole repo. New external calls, permission changes, and trust‑boundary crossings get flagged for the passes below.

2.0

Detect deterministically

Slither and Aderyn run in a network‑isolated, read‑only container. Tool errors produce an explicit INCOMPLETE report — never a fabricated clean pass.

analyzer pass · sandboxed
runtime
Slither + Aderyn, Docker --network none --cap-drop ALL
scope
diff-scoped: changed functions, new callsites, trust-boundary deltas

3.0

Triage with citations

An LLM constrained to three cited operations: reclassify a severity, dedup into an equal‑or‑higher one, or add a finding — only with a cited line range. It assigns no score, and any uncited operation is discarded and counted.

triage policy · temperature 0
allowed
reclassify (original preserved) · dedup (never escalates) · add (cited lines only)
forbidden
scoring · inventing findings · operating without a citation

4.0

Prove by execution

Criticals are reproduced on a fork of the target chain — Foundry against live state. A finding that survives the fork is confirmed; one that doesn't is reported as unproven. Reading code is opinion. Running it is evidence.

5.0

Anchor the verdict

The verdict lands on‑chain: commit hash, findings hash, risk score, agent identity. The score comes from a published rubric — anyone can recompute it from the findings alone, then check it against the chain.

What Rextor can't do

The integrity rails, in plain words — the refusals are the product.

It can't invent findings.

Every operation carries a cited line range or it is discarded. The agent never scores anything — the published rubric does, and anyone can recompute it.

It can't fake a clean pass.

A broken analyzer produces status = 1, attested on-chain — a riskScore: 0 can never masquerade as "all clear".

It can't be hijacked by PR content.

Titles, comments, and code are adversarial by assumption — rendered inert, prompt-injection hardened, simulation sandboxed.

It can't lose money.

The attestation key has no fund path. Worst case from key theft: visible, attributable bogus attestations. There is nothing to steal.

Which chains does it run on?

Tempo testnet runs the full loop today, and verdicts anchor on HyperEVM mainnet as of 2026‑09‑21. Ethereum, Base, Arbitrum, and Robinhood Chain ride the same deterministic pass with home-chain anchoring. Solana lands Oct 2026.

What is a "verdict on-chain"?

Every review ends with a small record written to the blockchain — commit hash, findings hash, risk score, agent identity. After it lands, nobody can edit it, including us. See one ↗

Does this replace my auditor?

No. Rextor makes every pull request an audit event between the human audits. Your annual engagement still matters — this is the continuous layer underneath it.

What happens when the tooling breaks?

The run marks itself INCOMPLETE and attests that on-chain. A broken analyzer can never look like a clean pass — failure is a visible, checkable state.
